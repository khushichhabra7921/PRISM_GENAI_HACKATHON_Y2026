# Synthetic regression kit (NOT official data)

Everything in this folder is **synthetic**, generated by `scripts/make_synthetic_kit.py` (seed 2026) from general
knowledge of Android Settings menus and common troubleshooting advice, written with the official kit's brand names
(TechCorp / Nexa). Every JSON file carries `"metadata": {"synthetic": true, ...}`. It uses the shared Settings
catalog `../deeplinks.json`.

| File | Contents |
|---|---|
| `siis_responses.json` | 60 customer-care style troubleshooting articles (plain text, `Settings > A > B` menu paths), mixing auto / manual / critical steps |
| `queries.json` | 106 user complaints (Battery, Display, Camera, Performance + Connectivity, Navigation, Sound…) incl. 10 multi-symptom and 10 expected `no_match` |
| `paraphrases_heldout.json` | 101 unseen paraphrases of 32 queries + 12 unseen negatives; **cache benchmarking only, never pre-warmed** |
| `samples/` | 5 gold input → output pairs in the API response format |

Used by `tests/test_pipeline.py`, `tests/test_validate.py` and `bench/run.py`. The official kit (`../input.txt`,
`../siis_responses.json`) is evaluated by `tests/test_official.py` and `bench/official.py`.

Deliberate test properties:
* Tokens are random, so deeplinks can only be matched on `description` / `message` / `cna_description`.
* Parent menus (`Display`) and their child screens (`Display › Navigation bar`) both exist.
* Three screens mentioned in SIIS text are intentionally missing from the catalog
  (`Display › Touch sensitivity`, `Advanced features › Motions and gestures`,
  `Accessibility › Interaction and dexterity`) to exercise `voiceassist://dummy_positive`.
